Heart Disease Prediction using Logistic Regression
Overview

This project predicts the likelihood of heart disease using the Framingham Heart Disease dataset and a Logistic Regression model built with Machine Learning techniques.

The project includes:

Data preprocessing
Exploratory Data Analysis (EDA)
Feature scaling
Handling imbalanced data using SMOTE
Logistic Regression model training
Model evaluation using classification metrics and ROC Curve
Technologies Used
Python
Pandas
NumPy
Matplotlib
Seaborn
Scikit-learn
Imbalanced-learn (SMOTE)
Dataset

Dataset used: framingham.csv

Target Variable:

0 → No Heart Disease
1 → Heart Disease
Features
Data Cleaning & Preprocessing
Class Balancing using SMOTE
Logistic Regression
Confusion Matrix
ROC Curve
Accuracy, Precision, Recall & F1-Score
Project Structure
├── framingham.csv
├── heart_disease_prediction.ipynb
├── README.md
Results

The model achieved improved prediction performance after balancing the dataset using SMOTE, especially for identifying heart disease cases.
